## Hi there 👋

Hi, 我是弥澄亮。 一名在“人类认知”与“机器语义”之间搭建桥梁的软件工程师。

我热衷于探讨复杂系统中的意义建构、概念建构与策展。善于倾听、汇总、调查与整合信息，梳理脉络，暴露出结构，便于团队的决策与下一步的行动。

Tex的作者高德纳编写了长达近半个世纪的学术专著，还能始终保持概念的完整；Linux内核作者林纳斯・托瓦兹面对各个开发者提交过来的邮件Patch进行review，他的大脑也恐怖地对整个 Linux 内核代码保持着惊人的统一。
这两位前辈对信息处理，对概念完整性的保持，令我感到震撼。

他们引发了我的思考和愿望——如何让普通人、普通团队也能够像那两位前辈一样，对生活、对个人上各种各样大大小小的信息，对工作上、对团队上……也能够达到如此高的效率与质量，以解放出人类更多的时间，能够去做更多自己想做的事情。

随着 GPT 一类的大语言模型技术的兴起，让我看到了突破口，我深耕于人机协作 HMC，我想能够借助 LLM 的力量，能够让普通人也能够达到那两位前辈那样强大的心智模型、信息处理能力。
